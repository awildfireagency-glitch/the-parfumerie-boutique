# The Parfumerie Boutique

Perfume catalog with notes pyramids and Messenger ordering.

- `catalog.js` is generated from the "Perfume Picture Menu" sheet: export it as CSV and run `python3 tools/build_catalog.py menu.csv`.
- `notes.js` holds notes pyramids, keyed by catalog id.
- Orders go to https://m.me/theparfumerieboutique
